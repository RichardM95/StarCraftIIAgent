# SC2图标绘制技能

- **新绘**：从玩家看到的位置和玩法说明出发，写出主体、动作与可见结果。从当前任务提供的参考中选一张同用途构图参考和一张同材质或派系参考。把参考与制作描述交给绘图工具，输出候选原稿与目标尺寸预览。
- **重绘**：先查旧图用途，定下必须保留的身份特征，再按下文处理构图、光照和材质。
- **审稿**：游戏纹理从「看压缩后的图」开始。设计任务交付制作描述，样稿任务交付候选预览，需要游戏文件时再按目标规格导出；正式替换走素材事务。

例如制作范围支援技能图标时，画出施放源、向外分开的光流与两个可辨的受益对象。缩至实际显示尺寸后，若只见一个光团，就拉开起点与终点，再检查作用方向是否清楚。条目名称和具体主体以当前项目需求为准。

需要构图、材质或派系依据时，阅读 [SC2 图标美术规范](references/sc2-icon-art-direction.md)。项目素材、图板、原稿和逐枚审查记录保存在该项目的本地资料目录，不随通用技能分发。

## 先弄清玩家靠什么认出它

- 从消费组件的 UserData、Button、Actor 或界面查到有效纹理，记录条目 ID、游戏内含义、显示位置、素材提供者和同名覆盖。复用旧图时留存原 DDS、哈希、可见区域和透明边缘。一个文件兼作天赋与英雄头像时，两种裁切都要看。
- **英雄或兵种**以原图为身份参考，先指出必须保留的轮廓、眼位、冠甲或口器。优先调整裁切、侧光和材质。**技能效果**选一个玩家能看到的动作及其结果，例如橙色弹丸撞在厚冰盾上。**职业或阵营徽记**保留原有标志的形状与朝向，再设计它的载体和表面。
- 在现有图标库中找同用途、同阵营的参照。官方来源可用[官方资源技能](../sc2-official-assets/SKILL.md)定位。给参考分工：旧图决定「是谁」，同组游戏图决定笔触、裁切和明暗，玩法说明决定「发生了什么」。标明参考提供者。

## 把构图和材质写进制作要求

用一句可画的描述交给制作者：**哪个主体，在做什么，玩家从哪个形状或接触点能看出来**。再补上必须保留的身份特征、主要材质、光源和系列参考。精确数值留给说明文字。

从当前任务的参考中选择同用途和同材质的样本，制作要求注明项目内样本标识、借用的具体结构、最亮位置与主体暗面。单位整体、部件特写与简洁状态符号各按用途安排细节。审稿时将候选与所选样本放在同一背景、相同显示尺寸下比较。

| 遇到的问题 | 下一版具体改什么 |
|---|---|
| 只有光团，看不出支援范围 | 画出施放源和两块分开的受益甲壳，让菌毯上的光流到达它们。缩小后仍能看到起点与终点。 |
| 冰、骨和金属像同一种塑料 | 用透光的暗面与崩口表现冰厚度，用分层接缝和磨亮的刃口表现骨甲，用窄高光与磨损边缘表现搪瓷金属。把最强明暗留在作用点。 |
| 护盾增益与护盾衰减太像 | 前者画完整承力面和弹丸撞点；后者让裂口切穿外轮廓，碎片与盾体拉开距离。两枚并排看剪影。 |
| 虫肢结构奇怪或英雄换了脸 | 对照原头像的特征与裁切。效果条目可只画相关甲片、培养囊或作用目标；身份图标用原图做定向编辑。 |

成组重绘先选最容易混淆的一对或一枚身份样稿，经过小图审查再扩展。按本次授权核对指定制作与审查模型；保存提示词、原稿和获选版本。返工只改被指出的问题，以通过的样稿为系列参考。

## 看压缩后的图

1. 将**候选 DDS 回读解码**，和旧图、同组参照按界面实际像素并排。以 128 像素图标为例，再看 64 像素预览；对透明图叠加实际界面底色检查黑边、光晕和裁切。
2. 先隐去文件名和说明，让审查者写下「主体、它在做什么」，再揭示条目含义。把易混的增益／诅咒或生物／机械感染并排比较。若主效果读反、英雄身份变化或只能靠标签区分，记下误读及下一版要改的轮廓。只有细纹消失而主效果清楚，可记录后通过。
3. 分开记录视觉判断和文件格式。项目要求 **128×128、单层传统 DXT5** 时，可用下列只读检查（需 Pillow，可一次传入多个文件）。要求完全不透明时加 `--opaque`。

   ```powershell
   python skills/sc2-icon-art/scripts/check_dxt5_icon.py --opaque "候选目录/图标.dds"
   ```

   此规格顶层长度为 16384 字节，传统头加负载共 16512 字节。即使解码器能显示，仍要检查头中声明的长度。其他尺寸、压缩、透明或 mip 契约按目标组件分别验证。

## 合入与交付

通过[共享工具技能](../sc2-shared-tools/SKILL.md)在实际素材组件准备替换，核对事务清单只含获选路径，保留大小写和历史拼写。提交前比较原文件哈希；提交后回读正式 DDS 与候选比对，并从消费项目解析纹理，检查同名遮盖。提交状态不明时先查原事务。交付原版／候选小尺寸预览、原稿、逐枚审查结论和备份入口。离线格式和视觉结果单列；`Editor accepted` 与 `packaged runtime passed` 各需对应环境的观察记录。
