## 八类需求回查

这些回查记录观察依据，供后续创作选择参考。规则是否改善新图的生成结果，需要另行制作和审稿。

| 需求 | 对应参考 | 本次观察与制作要求 |
|---|---|---|
| 单位 | Taldarim-046、CovertOps-043 | 侧翼、正面与负形形成不同身份，先保留这些结构再加小部件。 |
| 建筑 | Taldarim-043、Purifier-026、Umojan-001 | 纵向轮廓、宽底座与顶部亮部各有辨识作用。 |
| 机械特写 | Icons-7bf3f4dfb1、Icons-52899bc3d4、Moebius-077、CovertOps-067 | 甲片暗缝、镜片高光与枪身受光边分别解释结构。 |
| 虫族甲壳 | Webby-034、Webby-084 | 软囊被硬壳包住，甲片层叠由厚暗缝隔开。 |
| 护盾 | Purifier-007 | 壳面有前后亮弧和较暗内部，保留内部空间。 |
| 光束 | Ihanrii-024、Purifier-044 | 用弧线与撞点、斜束与落点表达两种运动关系。 |
| 状态符号 | Icons-04500852d5、Icons-951b8a2a32、Moebius-092 | 根据用途选择简洁符号或带材质的象征物，并检查线间距。 |
| 派系变体 | CovertOps-067 与 SCORE 全量图中的 Moebius-087 | 对应枪身保留相似结构和取景，蓝色、红色随各自系列安排。 |

## 格式与边缘回查

本次还查看了全部 84／90 像素输入，以及暗色建筑和齿轮的明暗双底预览。源文件中多数有透明像素，具体透明位置各不相同。原图按自身尺寸保存，对照时再缩到实际显示尺寸。最近邻放大仅用于观察已有像素；材质判断同时回看原尺寸。

本页样本来自用户提供的研究资料。SCORE 记录到分包，个人作者未逐一核实；其余来源未核实。后续分发或正式使用时按具体来源核对许可。
