# 单位外观与 Actor

先核对目标项目，再沿 Unit → 单位 Actor → Model → M3/贴图查询。未显式填写的字段通过父级、类默认和依赖合并取得；记录来源及模型资源是否可读。[SCORE 案例](../sc2-art/references/score-actor-cases.json)仅保存本地声明。

- **轮廓与比例。** 在常用游戏镜头和单位群中看大小、武器朝向、关键负形、选择范围与地面接触。模型比例与玩法占地分别核对。
- **材质与配色。** 把装甲、软组织、透明部件、自发光和队伍色分开。参考同系列样本的亮暗面积和标志色，检查近景与战场视角。贴图与材质槽、继承的替换事件一并核对。
- **身份与变体。** 保留能辨认兵种或角色的部件。新变体通过轮廓、材质和标志色表达区别，并检查与已有单位并排时的识别。
- **状态与动画。** 查看实际使用的出生、站立、移动、攻击、死亡、建造、放置、变形和飞行形态。对照事件与模型动画，检查附着点、特效比例及销毁时机。
- **肖像交接。** 外观改动涉及头部、装甲或派系身份时，加载[单位肖像](../sc2-unit-portrait/SKILL.md)，同步核对动态肖像和静态回退。

具体事件、消息、父级、默认关联和材质替换规则以 [Actor 系统](../sc2-actor-system/SKILL.md) 为准。XML 编辑还需 [Catalog 技能](../sc2-catalog-xml/SKILL.md)。

参考[四组单位与肖像观察](../sc2-art/references/editor-preview-observations.md)选择结构依据：重装体块、机械核心与肢间负形、虫族冠甲与分节叠甲。八张静帧由用户提供，对应 FirebatC、DragoonI、HydraliskW、HydraliskPZ。实际改造时仍需解析目标资源链，记录对象、模型、镜头和照明；缺纹理或未解析依赖单列。颜色变化先区分材质、灯光与队伍色来源，一次预览只能支持当时可见的状态。

交付参考与候选的同视角对照、对象及资源清单、继承变化、静态检查和实际预览结果。游戏状态下的动画与队伍色验证按实际观察记录。
