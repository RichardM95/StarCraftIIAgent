Answer ordinary read-only queries from targeted evidence. Save reusable project conclusions in [project data](project-data.en.md), and general findings with sources/scope in the relevant suite reference.

Query tools/sc2-catalog-query.py for the project and active dependencies, then inspect raw XML. For official/partner precedents use tools/sc2-reference-query.py with component, family, language and output limits. A sample is not effective-value evidence. Reuse unchanged evidence within a task.

Project design/implementation facts belong in their project topics. Stage files under runtime/tmp/ and reports under runtime/reports/ only when needed; a single query need not create durable docs.

For archived-chat lessons, follow [retrospective evidence](retrospective.en.md), including later corrections, current source and observed tests. Update existing topics/checkers. Historical advice, candidate fixes and untested performance claims retain their evidence limits.
