# 2026-11-03 更新说明

本次更新让 AI 更容易使用可编辑的 GUI 触发器完成地图功能，也改善了数据查询、测试和日常操作的可靠性。

## 可以直接使用的新能力

- 用事件、条件、动作和变量描述需求，查询局部触发器逻辑，再预览、验证和提交 GUI 修改。支持创建功能和改造已有分支。
- 从受支持的 GUI 逻辑离线生成 Galaxy，检查语法、符号和类型，并生成独立测试包。无法生成的调用会指出对应节点和原因。
- 查询谁直接使用某个行为、模型或单位。编辑器保存后，下一次查询会刷新引用索引，多对象文件只重算受影响的对象。
- 结合官方依赖缓存解释数据继承来源，并用游戏探针读回实际值。测试启动器使用窗口模式。

## 日常使用更稳妥

- 修复列出项目后项目路由丢失、后台任务失败却返回成功的问题。
- 修复动作演算体和应用行为效果的默认关联误报，依赖不完整时给出待核实诊断。
- 强化地形工作副本检查，游戏测试与完整回归共用占用检查。
- 提交断线后可以查询原候选的应用状态，重试会返回已有提交记录。
- 不同项目共用状态目录时，能确认归属的损坏事务只阻断对应项目。
- 大报告支持按页读取。Windows 符号链接测试因权限跳过时，可以按需请求 UAC 补验。

## 文档与分享

- 中英文 README 按只读调查、指定地图和主 Mod 初始化分流。
- 新增保存后反查、撤离区接线和提交恢复的对话示例，并检查示例里的操作名和参数名。
- 忽略本机配置、缓存、测试产物及私人工作回执。保留通用测试、依赖锁和第三方来源说明。

## 使用前

共享 CLI/MCP 使用独立 Python 3.12+ 环境。离线 Galaxy 前端还需 Node 22+ 并完成构建。安装步骤见 [安装指南](../../setup.md)，日常操作见 [共享工具指南](../../wiki/guides/shared-tools.md)。

静态检查通过记录为 `static validation passed`。编辑器保存与游戏运行各自需要对应证据。已有 B98370 实机结论适用于原测试地图和归档。
