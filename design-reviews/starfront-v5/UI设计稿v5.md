# 《星际前线：孤军生还》UI设计稿 v5

版本：2026-10-29 · 手机横屏交互与美术制作规范。配套：[系统设计稿v5](系统设计稿v5.md)。

系统数值与结算以系统稿为准；本稿定义玩家如何看见、操作、比较和理解它们。此处线框是结构稿，尚未经过真机触控和视觉验收。基准画布2400×1080设计像素，支持16:9–20:9；设计像素、世界单位u、设备逻辑尺寸dp分别使用。

## 1. 视觉方向与信息优先级

保留人族厚装甲、切角、军用仪表和战术通信的辨识度。战斗采用低噪声平面底板，舰桥和整备采用更多拼接钢板与机械细节。战损纹理不覆盖正文或数值，所有发光都服务于状态。

原稿修订：减少动态头像常驻面积；取消血条2Hz闪烁、战斗打字机和全屏核爆白闪；避免把禁用状态画成黄色危险标志；危险提示不能与矿晶／瓦斯使用相同形状。战斗不显示完整装备卡与人物半身像。

优先级从高到低：敌方致命预警与玩家位置 → 生命／冲刺／技能状态 → 标记目标与首领阶段 → 资源／波次 → 构筑反馈 → 装饰／闲聊。友方光效不得覆盖危险地面边界。

### 1.2 字体与单位

中文采用可授权的清晰黑体，候选Noto Sans SC；英数可用Rajdhani，但数值0/O、1/I必须清楚。Orbitron等装饰字只用于标题，不用于伤害或倒计时。

| 信息 | 设备逻辑尺寸初值 | 规则 |
|---|---|---|
| 正文、卡牌说明 | 16sp，辅助说明不小于14sp | 按系统字体缩放；大字体模式重排，不截断负面代价 |
| 核心资源、生命 | 18–22sp | 等宽数字，位数变化不推动按钮 |
| 页面标题 | 24sp | 最多两行；过长换行 |
| 技能冷却 | 20sp | >3秒整数向上取整，≤3秒显示一位小数 |
| 机制标签 | 14–16sp | 同时有图标、文字，避免全英文缩写 |

世界距离显示为“射程480u”，并在首次详情说明“游戏内距离”；短卡可写“中程”，详情保留精确值。伤害显示初值与受当前装备影响后的值，不能只显示未经加成的基础值。

## 2. 布局、适配与触控

按设备实际安全区向内布局，左右额外留12dp、顶部8dp、底部12dp；不能用固定48设计像素代替刘海／手势安全区。两侧控件与中心战场通过锚点分离，20:9增加视野，不把所有按钮等比拉宽。

- Android可点击目标至少48×48dp；主要技能按钮直径72dp、冲刺64dp，两者热区边缘间隔至少12dp。最小热区不可互相重叠；外扩8dp只能在仍有间距时使用。
- 移动摇杆基座直径96dp、有效拖动半径40dp，死区6dp；左下可配置区域内首次落点生成。超过基座距离时基座跟随，但手指ID不换、不吞另两指。
- 技能／冲刺锚点支持拖动、0.85–1.3倍缩放；实际热区不低于48dp。设置提供恢复默认、左右手镜像、测试按键和保存；拖动布局只在设置页进行。
- 左右手镜像只交换战斗操作区；生命、暂停、首领条不换到陌生位置。配置分别保存，首次出击可在训练区切换。
- 大字体模式下，HUD保留关键数值，折叠武器缩略条；商店四列改为两列滚动。需要横向对比的替换窗口改为上下对比。

### 2.1 输入竞争与点击集火

UI捕获优先于世界点选。被摇杆、技能、冲刺捕获的手指不会点击怪物；被通讯窗捕获的点击只展开通讯。拖动过程不补发点击。多点状态下第三指可点标记，但不得抢占已经捕获的移动指。

世界点击≤250ms、移动<8dp才成立。点击怪物的48dp选择区只负责选择，不改变碰撞体；多个目标选择区相交时取触点最近的实体中心，优先机制目标。无目标点击不解除当前标记，点击同一目标解除。点击不会自动施放职业技能。

标记显示菱形准星、头顶“集火4.0s”、目标条描边；屏幕顶部显示小型“集火：神经囊”，目标离射程时写“超出射程”，不让玩家误以为枪坏了。目标死亡立即清除，武器恢复自动索敌。

技能长按显示范围和自动目标；释放施放；向按钮内侧明确的取消区拖动后显示“松开取消”。无目标显示“范围内无目标”，不进入冷却。冲刺按钮短按沿移动方向，长按只预览方向，不新增第二套瞄准操作。

### 3.1 生命、护盾与资源

生命条必须常驻；护盾条仅有有效盾时出现，数值为当前实际可吸收量。上限按系统稿最大生命50%处理，过量授予不显示虚假数值。临时盾最后1秒用边线缩短表示到期，不用快速闪烁。

生命<30%时显示稳定红色角标、一次短音或短震动；不常驻红色屏幕滤镜，不以持续蜂鸣淹没敌方预警。生命成本以“−12 兴奋剂”小字表示，避免误认为被敌人打中；不播放受击警报。

战斗只显示矿晶和当前持有瓦斯。研究数据在结算页出现；局外界面只显示研究数据，不把上局已经清空的矿晶和瓦斯放在顶部制造误解。矿晶计数可跳数字，但每次拾取不生成飞过整屏的光点。

### 3.2 技能按钮状态

| 状态 | 冲刺／技能呈现 | 交互与反馈 |
|---|---|---|
| 可用 | 完整高对比轮廓、图标、名称 | 按下立即亮边；成功施放才给短震 |
| 冷却 | 遮罩＋剩余秒数 | 点击显示剩余时间，不播放错误大警报 |
| 无合法目标 | 图标保持，附小斜杠 | 点击短提示“范围内无目标”；不消耗 |
| 长按预览 | 范围显示、目标描边 | 指向取消区时明确变为取消文案 |
| 正在冲刺 | 按钮显示位移箭头 | CD已开始，第二次点击不缓存冲刺 |
| 附带生命成本 | 技能名旁红色小滴图标 | 预览显示“消耗当前生命12%，不会降至0” |
| 技能成本不足 | 预留通用不可用状态 | v5兴奋剂至少保留1生命，不错误地锁住低血技能 |

按钮不显示“工程召唤上限”这种内部术语；C06达到两炮台时预览为“部署新炮台，回收最旧炮台”。全场8友军配额不足时显示“支援已满，等待现有支援消失”，不得假播放部署效果。

### 3.3 武器、支援与状态

四武器缩略格只显示图标、等级、分支A/B，支援两格显示图标与是否损坏／配额。没有武器换弹系统时不得设计弹药条；W01B等周期停火可用武器格短扫条，不能伪装成玩家需要按换弹键。

战斗状态最多三枚：伤害相关、减速、救命是否已用等，超出合并“+N”；完整列表在暂停详情。HUD装备区域只读，战斗点击不弹全屏属性阻断走位。

### 3.4 首领与波次

普通波显示倒计时；首领波显示已战斗时间，90秒后出现“压力上升”，不能仍显示一个到零就获胜的倒计时。首领条标出70%／35%等实际阶段点，阶段名称短显示1.5秒。

W12神经囊有独立血条、8秒计时和可点轮廓；主首领条下说明“击破神经囊可减少增援”。漏打后显示“增援到达”，不显示“任务失败”。旋转束显示起始方向、顺时针箭头和预警倒计时，不能依赖语音才能判断。

## 4. 整备：升级、购物与研究同屏衔接

每波结束后打开一个整备页。顶部持续显示“已完成第N波／下一波N+1”、生命、矿晶、瓦斯。中部货架与装备；底部列出待选升级／核心研究。玩家可先逛货架；进入下一波前必须选完升级与本次研究。

### 4.1 卡牌信息与购买

一张普通卡保持名称、类型／标签、最多两行收益、一行代价、价格和按钮。长说明点击展开，不缩成小字。每张权衡道具负面代价在购买前可见；例如“护甲+8／移速−5%”，不能只在详情里藏代价。

| 场景 | 必须展示 | 购买行为 |
|---|---|---|
| 有空位且钱足 | “放入武器槽3”或“支援1/2→2/2” | 一次点击购买，成功后货格变已购买，保存状态 |
| 武器／支援已满 | 新旧伤害、射速、射程、控制、分支、回收额与净花费 | 打开比较，明确选择被替换项后确认；取消不花钱 |
| 同武器已有两把 | “同型号上限2” | 不允许第三把，不用灰色按钮无解释 |
| 道具12种已满 | “先回收一种道具” | 打开回收抽屉，回到原货架仍保留选中卡 |
| 同道具达到上限 | 已持有2/2 | 随机货架正常不出；历史锁货仍可见但禁止买 |
| 余额不足 | 价格与“还差X矿晶” | 详情仍可读，不自动开充值入口 |
| I28合同预支 | 即得60、未来3次各扣25、不能回收 | 明确债务确认一次，不当作普通0元免费奖励 |
| I40共生甲片 | “武器容量4→3” | 只有持有≤3把时出现，确认页显示容量改变 |

属性比较不用单一“战力+10%”替代所有信息。W08A站定炮与W02A走射枪应显示“站定强化／移动强化”的冲突说明。不能在敌人数未知时承诺“总伤害一定提升”。

### 4.2 等级与分支

升级三选一显示选前→选后实际值，如“护甲8→12，减伤13.8%→19.4%”；如果属性已封顶，该项不出现。连续两次升级显示“第1/2次”，允许先查看装备，但不能跳过奖励无提示出击。

武器升Lv3先打开A/B对比：左侧主机制、中央收益、底部代价；两个按钮都显示最终费用。选定未确认时可返回。确认前写明“本局分支固定”；确认后扣费并保存。武器图标显示“A穿透／B超频”等短名，不能只显示金框。

### 4.3 核心研究

W2／W5／W8整备顶部亮起“核心研究”，瓦斯20足够本次研究；窗口显示科技槽1/3、2/3、3/3。先选组偏好再生成三项，本次生成后保持不变；组偏好可在每次新研究前调整。

三张研究卡必须有：科技名、来源题材短标签、改变打法的一句话、触发、收益、代价、装备适配、20瓦斯成本。示例：“攻城协议｜站定0.8秒后爆破+35%；移动时爆破−15%”。

适配反馈是具体文字：“你有2把爆破武器”“会影响兴奋剂冷却”“需要能量武器”。未满足前提的科技不进入三选一；全档案可查看且显示解锁／装备前提。选中后确认，禁止误触即支付；锁定后写“本局已研究”，不画可拖动替换槽。

### 4.4 刷新、锁定与回收

锁按钮有独立48dp热区，不能与购买按钮重叠。锁定显示挂锁＋“下波保留”，最大2格；第三次点击说明“最多保留2件”。刷新确认显示将刷新的格数，锁格不闪动；全部已锁／已购时禁用并解释。

刷新按钮明确“免费1次”或“刷新5矿晶”，后续8／11／14……；I27优惠在按钮价格直接体现。不会让研究卡或升级奖励一起换掉。

回收抽屉显示实际返还金额和移除后的属性，I28显示“合同不可回收”，I14已消耗显示“救命已用，代价仍在”。装备被售卖后更新适配提示但不退还已研究科技，售卖前提示可能失去科技触发条件。

### 4.5 离店与对话

出击按钮有待选择时显示“还有1项研究”，点击滚动至对应区域，不能静默按默认替用户选择。确认出击先完成保存，成功后进入3秒可跳过准备倒计时；保存失败停留整备并允许重试。

后勤交流默认一行可折叠，不占固定左半屏。点击汉克／艾拉等头像打开侧栏，可随时关闭；不将对话当作购物的必经步骤。不购买医疗时艾拉不会重复斥责或阻止出击。

## 5. 危险可视化与场景秩序

### 5.1 地面与弹道规范

| 威胁 | 形状与动画 | 初始预警时间／可见性 |
|---|---|---|
| 毒爆 | 空心圆＋向内收缩三角刻度，锁位后中心不跟随玩家 | 0.8秒；外圈始终实线，不混成掉落物 |
| 潜伏者 | 长矩形斜线填充＋前进箭头 | 0.9秒；箭头标出出刺方向 |
| 破土突刺 | 双圆圈＋中心地裂图标 | 1秒锁位；从追踪状态变锁定位时有明确音色变化 |
| 酸潭／酸云 | 低饱和填充＋重复危险斜线边界 | 0.9秒生成预警；危险结束边界立即消失 |
| 旋转束 | 起始扇区轮廓＋顺时针弧箭头，扫过路径带短尾迹 | 1.2秒；攻击本体与预警线用不同实虚线 |
| 屏外酸刺 | 屏边小箭头＋短提示音 | 不以穿屏瞬间才出现的白点代替预警 |
| 友方地雷／焦土 | 青色小标＋无红色斜线，友方范围默认不常驻 | 低特效仍保留地雷触发轮廓 |

玩家位置有始终可见的白色脚环和朝向缺口。脚环不能与敌方落点同形同色。攻击装置有小机械图标和简短血条，非交战不显示完整姓名；心控异虫有明确青色项圈轮廓，避免被当敌怪躲避。

### 5.2 层级与遮挡

渲染逻辑由低到高：地表 → 场景装饰 → 敌方预警填充 → 尸体／掉落 → 单位 → 友方攻击光效 → 敌方预警轮廓／弹丸 → 玩家脚环与目标标记 → HUD。处于单位下方的预警边界也需通过上层描边保证可见；不能让深色怪群完全压住红圈。

单一范围爆炸亮度和面积受控；连续命中数字可合并成0.25秒总值，只给暴击／首领关键命中加大字。毒爆死亡不播放与实际爆炸同样的危险圈，避免死亡特效误导。

三档特效：完整、标准、低。低档减少烟、火星、尸体、友方拖尾和飘字数量；敌方预警、弹丸、实际伤害边界不削减。选择低档不改变任何碰撞、冷却和伤害。

## 6. 舰桥、档案与结算

### 6.1 舰桥导航

四个明确入口：出击、军械档案、研究终端、人员通信。主视觉是休伯利安后勤舱，默认静态图配局部灯光；动态半身像仅在通信页加载，减少常驻成本。

出击页先选职业，再选该职业允许的初始武器；v5每职业只有一个指定初武，界面不虚构可选列表。显示技能、被动、起始属性及一句打法，附“训练试用”。难度和启用内容池在下一层，不塞入职业卡。

研究终端顶部只显示研究数据。解锁按钮写“解锁新选项10数据”，不写“永久战力+10%”。已解锁条目有启用开关，关闭影响下一局；不满足最小内容池时说明缺少哪类数量。角色需要的初武与适配科技不能被误关。

军械档案可按载体、工程、精密等筛选；标签不显示“2件套／4件套”。各条目展开原版灵感与本作改编，来源说明放在详情底部，不占战斗卡正文。八套示例构筑显示必需机制、替代项和弱点，不提供“必胜”推荐。

人员通信默认列“新对话”，每人独立未读角标，阅读后消除。文本立即完整显示；可选打字机、语音重播和历史回放。返回始终回到原来的舰桥页，不丢失解锁筛选。

### 6.2 结算与重伤

成功标题“撤离成功”，失败“紧急撤离／任务未完成”。显示到达幕、波次、战斗时长、整备时长、可选阅读时长、主要伤害来源和本局构筑。

研究数据按已完成幕、首次首领奖励分行列出；已有奖励标记“已领取”，保存完成后才启用“再次出击”。矿晶／瓦斯明确“本局资源已结算，不带入下局”，不兑换为永久战力。

复盘提供最多三条有证据的提示：“最后伤害：潜伏者穿刺”“本局未使用集火标记”“第三幕酸潭累计承伤”。没有工程事件数据时不生成伪精确评价。不把所有失败归因为玩家需要刷永久属性。

## 7. 暂停、续玩与异常状态

- 暂停菜单：继续、当前构筑、设置、返回舰桥；后台自动暂停。恢复有3秒倒计时，可立即继续，玩家位置和危险状态在计时内冻结。
- 波中返回先说明“下次从本波开始恢复”；不承诺逐帧存档。救命消耗记录保留；不能在UI里显示已恢复免死。
- 发现中断档案时显示“继续第6波／放弃本局”；放弃需确认，显示未结算内容，不误删局外解锁。
- 当前档损坏时说明“已恢复到第5波整备”，继续与返回舰桥并列。仅在实际恢复成功后出现继续按钮。
- 保存状态为保存中／已保存／失败可重试，平时不弹打断窗口；失败时阻止离开整备以免购买丢失。界面不展示JSON字段或文件路径。
- 工程版本无法识别旧内容ID时进入恢复说明，不把缺失装备静默变成空槽；具体兼容转换由工程实现记录。

## 8. 声音、动效与辅助功能

按钮按下反馈80–120ms、面板进入150–220ms、关闭120–180ms；动效不延迟实际输入。减少动态模式取消扫描线移动、CRT畸变、色散和面板位移，仅保留状态切换。

危险音、技能就绪、资源拾取、语音四类独立音量。拾取音最多每0.12秒一次，敌群命中音限制并发；危险音可压低其他声音，不能被射击声抢走全部声道。震动分别开关：受击、危险、技能；震屏默认低，可完全关闭。

辅助设置：大字体、色觉辅助、危险边界强化、低特效、减少闪烁、关闭震屏、关闭闲聊、字幕大小、背景不透明度、左右手与按钮布局。关闭闲聊仍保留必要机制字幕；关闭语音不影响危险视觉信息。

默认不开快速闪光；核信标使用局部扩散冲击波、短促低频音和战术标记表示，不整屏闪白。头像采用低频待机动作，静态替代必须可用。

UI可用Godot Control、容器、锚点与Theme组织；具体节点结构留给工程按项目实际实现。世界和UI坐标通过唯一投影接口映射，选择热区使用屏幕逻辑尺寸，战斗判定使用世界u。按钮、价格、属性和冷却均读取系统数据，不在场景内另存一份常量。

界面需读取的状态包括：本局阶段、生命／有效盾、技能可用与冷却、四武器等级分支、两支援状态、三科技、道具份数、待选升级、研究三选一、货架与锁定、债务、救命次数、存档状态、当前集火目标。交互命令为移动、冲刺、技能预览／确认／取消、标记、购买、升级、回收、研究、锁定、刷新、出击、续玩。所有命令失败都返回可显示原因，界面不能自行扣钱后等待战斗层纠正。

跨稿共用词：矿晶（局内购买）、瓦斯（局内核心研究）、研究数据（局外解锁）；武器等级Lv1–3；核心科技3槽；支援装置2槽；普通改装道具12种。首领波为4／8／12，升级奖励在波末选择。
